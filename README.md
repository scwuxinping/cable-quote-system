# 电缆厂销售报价系统

[![CI](https://github.com/scwuxinping/cable-quote-system/actions/workflows/ci.yml/badge.svg)](https://github.com/scwuxinping/cable-quote-system/actions/workflows/ci.yml)

面向电缆厂/经销商销售场景的完整业务系统：**型号规格库 + 材料成本计价引擎 + 铜价联动（自动获取/手工修正）+ 报价/审批/订单/回款全流程 + Excel 导入导出**。

Django + SQLite，单机即可运行，厂内网业务员用浏览器访问，无需安装任何客户端。

## 计价模型

```
铜材成本   = 导体重量(kg/km) × 铜价(元/kg，含升贴水) × (1 + 损耗率)
电缆成本   = 铜材 + 绝缘 + 护套 + 铠装/屏蔽 + 填充 + 加工费 + 人工及制造费用
销售报价   = 电缆成本 × (1 + 利润率) × (1 + 税率) + 运费
```

| 数据 | 位置 |
|------|------|
| 铜价来源（长江现货/上海期货/LME/手工） | MaterialPrice.source |
| 铜价生效时间 | MaterialPrice.date + created_at |
| 汇率 / 升贴水 | MaterialPrice.exchange_rate / premium |
| 导体重量/消耗定额 | CableSpec（理论值可按厂标校准） |
| 损耗率 | Material.loss_rate |
| 加工费 / 人工及制造费用 | PricingParams |
| 利润率 | 目标毛利率（目录价）+ 最低毛利率（底价） |
| 报价时的铜价快照 | Quotation.base_cu_price + 来源 + 时间；行级完整计价快照 |

## 功能一览

- **快速询价**：输入 `YJV 3x120+1x70`、`YJV22 4x16`、`wdz-yjy 4x16` 立即出成本、底价、目录价，
  附该规格**最近成交参考**（客户、日期、成交单价）
- **铜价走势**：工作台近 30 天走势图（涨跌标注），报价心里有数
- **报价单**：多行明细、整单折扣、运费；**客户阶梯价自动套用**（满 500 米 95 折、满 2000 米 92 折等，后台可配）
- **两级审批**：毛利低于最低线 → 经理审批；整单金额达到**大单阈值**（默认 50 万，可配）→ 经理审批 + 老板终审
- **销售订单**：已审批报价单一键转订单（金额快照），生产中 → 已发货 → 已完成状态流转，可取消
- **回款管理**：订单登记多笔回款（方式/备注），自动算未回款余额；工作台显示应收合计
- **月度报表**：工作台近 6 个月报价数 → 审批数 → 转单数 → 订单额 → 回款额
- **Excel 导入**：客户询价清单上传即生成报价草稿，未匹配行列出原因
- **价格维护**：每日材料价格 + 升贴水，来源/录入时间留痕；手工保存覆盖自动值
- **铜价自动获取**：`py -3.13 manage.py fetch_cu_price`（上期所沪铜连续；`--premium` 升贴水；`--price` 手工修正；`--rate` 汇率留痕），可挂 Windows 任务计划
- **规格库**：9 个系列 700+ 规格理论用量：YJV/YJLV/YJV22/YJLV22/VV/VLV/**WDZ-YJY（低烟无卤）/KVV（控制电缆 4-37 芯）/BV
- **权限**：业务员建单；经理审批；老板大单终审；成本明细仅经理可见

## 快速开始

环境：Windows + Python 3.13（`py -3.13` 可用）。

```bat
cd cable_quote_system
init.bat     :: 首次：安装依赖 + 建库 + 种子数据
start.bat    :: 日常：启动服务
```

本机访问 <http://127.0.0.1:8000>，局域网业务员访问 `http://本机IP:8000`（防火墙放行 8000）。

## 每天的使用流程

1. **铜价**：任务计划跑 `fetch_cu_price`，或在"价格维护"页录入
2. **询价报价**：快速询价看成本与历史成交 → 正式建单（勾选阶梯价）或 Excel 导入
3. **提交审批**：毛利达标的小单自动生效；低毛利或大单走经理（+老板）审批
4. **成交**：已审批报价单 → "转为订单" → 生产/发货状态流转 → 登记回款
5. **复盘**：工作台看月度报价/转单/回款趋势与应收余额

## 数据校准（重要）

- **材料价格**：种子数据为演示值（含近 14 天铜价演示历史），请在价格维护页改为实际值
- **理论重量**：按国标近似几何模型生成（铠装按两层钢带等效厚度估算）；差异可在 后台管理 → 规格库 逐条修改，
  或调整系列参数后 `py -3.13 manage.py shell -c "from quoter.specgen import sync_series; from quoter.models import CableSeries; print(sync_series(CableSeries.objects.get(code='YJV22')))"`
- **计价参数**：后台 → 计价参数（利润率、税率、加工费、人工制造费、大单阈值、有效期、公司抬头）
- **阶梯价**：后台 → 客户 → 编辑 → 阶梯价（起订总长度 → 折扣）
- **新增型号**：后台建系列（绝缘厚度表/芯数/截面/铠装）后 sync_series 生成

## Excel 导入格式

三列：`型号 | 规格 | 长度(m)`。型号兼容 `YJV22`、`WDZ-YJY`、`KVV`、带电压后缀等写法；规格兼容 `3×120+1×70` / `3x120+1x70`。

## 已知边界（二期可做）

- 铠装重量为估算模型，未按钢带层数/规格精细计算
- LME/长江现货无免费稳定接口，走 `--price` 手工换算录入
- SQLite 适合几十人内网；规模大可平滑换 PostgreSQL
- 报价单在线发送留痕、客户自助询价门户
